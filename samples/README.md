# Samples

This folder can hold example CSV logs (small, redacted).

Example generation on your Mac:

```bash
./scripts/demo-plot.sh
# -> creates data/demo_rtt_*.csv + .html
# copy a sanitized example here if you want to share:
cp data/demo_rtt_*.csv samples/example_rtt.csv
```

Do NOT commit real session data or phone numbers you haven't redacted.
